# Milestone acceptance

The authoritative status table is in [ROADMAP.md](ROADMAP.md). GitHub milestones organize the first concrete follow-up issues:

- [M0 — Verified Windows release](https://github.com/ViolaPeracia/chess-chaos-lab/milestone/1): release package, checksum, CI, Pages, and an honest GUI verification record. The keyboard and assistive-technology audit remains open.
- [M1 — Chess correctness and PGN](https://github.com/ViolaPeracia/chess-chaos-lab/milestone/2): broader rules regression positions and full PGN import/export round trips.
- [M2 — Engine reliability](https://github.com/ViolaPeracia/chess-chaos-lab/milestone/3): complete local engine games and deterministic crash, timeout, malformed output, and cleanup tests.

A milestone closes only when each acceptance criterion has linked test or manual evidence. Later milestones stay in the roadmap until their scope and dependencies are clearer.
