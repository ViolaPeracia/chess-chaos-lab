# Testing and evidence

Commands run on Windows x64:

```text
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo build --release --locked
npm ci --prefix site
npm run build --prefix site
```

Twenty-seven automated tests passed: the original 23 plus accessible square-name, corrupt-clock-save preservation, truncated/oversized-autosave, and combo-box focus-ID regressions. The original suite covers initial perft depths 1–3, legal AI moves, a 100-ply AI simulation, material evaluation, mate with undo/redo, resignation, illegal FEN, en passant, underpromotion, castling, draw rules, save recovery, three clock modes and time-forfeit rules, plain PGN round trip, UCI parsing and a subprocess fixture handshake. More FIDE edge positions and property/fuzz tests remain. The M0 branch used the commands above; the original baseline run used `--offline --locked`.

## M1 branch evidence

M1 adds reference perft positions 2–4 (depths 1–3), castling-through-check and discovered-check en-passant regressions, announced-move draw claims, insufficient-material and resignation edge tests, generated legal-game PGN round trips, nested RAV and comment/NAG/header/FEN round trips, invalid-input and resource-limit cases, 2,000 deterministic small malformed-input parser probes, variation navigation and autosave tests, and a file-import/UI row integration test. Three review regressions cover fivefold repetition on mainline and variation ancestor paths plus autosave, all legacy terminal save outcomes across save/load/export cycles, and fixed-height annotated move buttons with nested RAV, multiline comments, multiple NAGs and 5,000 virtualized rows. The perft counts come from [Chess Programming Wiki's reference results](https://www.chessprogramming.org/Perft_Results); draw distinctions follow [FIDE Laws of Chess articles 5 and 9](https://handbook.fide.com/chapter/e012023). PGN structure and Seven Tag Roster follow the [PGN specification](https://www.saremba.de/chessgml/standards/pgn/pgn-complete.htm). The malformed-input probes are a bounded property-style check, not a coverage-guided fuzz target.

PGN import accepts exactly one game. A second game or content after its result is an error; missing or malformed header quoting, illegal SAN, mismatched result tags, unmatched parentheses, excessive NAGs, and an invalid SetUp/FEN combination are tested. Export normalizes move numbers and whitespace while preserving the parsed tree, headers, comments, NAGs and result. Input is bounded to 1 MB, 50,000 nodes and 64 RAV levels.
