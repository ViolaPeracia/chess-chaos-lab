# Local engine integration

The application does not bundle Stockfish or any other executable. Enter the full path to a trusted local UCI engine executable. Select **Local UCI engine** as the opponent to play White against it, or select **Analyze (1 second)** in **Local UCI analysis** to inspect the current position. The adapter sends `uci`, waits for `uciok`, sends `isready`, waits for `readyok`, then sends the current FEN and `go movetime 1000`. Analysis displays the returned best move, last depth, centipawn score (from side-to-move perspective), nodes and PV. For opponent play, the core validates the returned best move before applying it. The app stops the child after completion or timeout.

The Stockfish observations below were reported in the earlier development smoke run and were not repeated during repository setup. Only run engines you trust. The supplied executable runs with the user's normal OS permissions. There is no sandbox, CPU/memory quota, persistent engine manager, option editor or engine-vs-engine UCI play yet. The local **test fixture** passed a subprocess round trip and a GUI opponent game (`e4 e5`). The official [Stockfish 19 Windows x64 release](https://stockfishchess.org/download/) passed a separate GUI opponent move (`e4 e5`) and one-second analysis (`g1f3`, depth 21, 764,570 nodes in the GUI smoke run). Its downloaded ZIP matched the release asset's published SHA-256 digest `3c8bf1f9ea66a09350a40df4f632288285ac206d99f33ab5842c408fc30b48a7`. Stockfish was used from a temporary directory and is not included in this app's ZIP. Do not interpret missing or mate scores as centipawn scores.
